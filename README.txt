Week 2 Weekly Assessment - Task 4

This folder contains a standalone solution for Task 4 from Week2_Assessment.pdf.
The PDF says to use a loan/customer dataset supplied by the trainer. Since no
trainer dataset was attached, this solution uses a deterministic synthetic
bank-loan dataset generated by loan_data.py. Replace make_loan_data() with your
trainer dataset loading step if one is provided.

Install:
  py -m pip install -r requirements.txt

Run:
  py task4_evaluation_and_tuning.py

Outputs (plots/models) are saved in the current working folder.
Random seed is fixed at 42 where applicable. Runtime and numerical values may
vary by computer/library version. The expected_output.txt records a sample run.
